Cerebro Digital Local: Obsidian + Python + LLMs

Automatiza la generación de notas, etiquetado e interconexión usando scripts y modelos IA de código abierto.

por Victor Martinez 2026-10-21 ⏱ 16 min de lectura

1. El Potencial de la Bóveda Local

Obsidian almacena datos en archivos Markdown planos. No hay bases de datos oscuras ni encierros en la nube (vendor lock-in). Esto significa que un script de Python puede leer, modificar y crear nuevas notas en milisegundos directamente en el disco duro.

2. Integración de LLMs Locales (Ollama)

Enviar notas de ingeniería privadas a APIs de terceros puede ser un riesgo. Usando herramientas como Ollama, puedes ejecutar modelos como Llama 3 o Qwen directamente en la RAM/GPU de tu laptop.

python 
import json
import requests
from pathlib import Path

VAULT = Path("/home/usuario/Documentos/ObsidianVault")
OLLAMA_URL = "http://localhost:11434/api/generate"

def analizar_nota(texto_markdown):
    prompt = (
        'Responde solo con JSON con las claves "resumen" (lista de 3 frases) '
        'y "tags" (lista de 3 tags técnicos en minúsculas, sin espacios). '
        f"Apunte de universidad: {texto_markdown}"
    )
    payload = {"model": "llama3", "prompt": prompt, "stream": False, "format": "json"}
    response = requests.post(OLLAMA_URL, json=payload, timeout=120)
    response.raise_for_status()
    return json.loads(response.json()["response"])

Descarga antes el modelo con ollama pull llama3 y comprueba que el servidor de Ollama está activo.

3. Arquitectura del Flujo Automatizado

  • Ingesta: El script escanea la carpeta Inbox/ usando pathlib.rglob('*.md').
  • Procesamiento: Lee el contenido del archivo, lo manda al LLM local por una petición HTTP, y recibe el análisis.
  • Modificación del Frontmatter: Python inyecta un bloque de metadatos YAML en la parte superior del archivo con las etiquetas (tags) generadas por la IA.
  • Movimiento: El archivo se traslada a la carpeta definitiva Zettelkasten/ y se renombran enlaces si es necesario.

Un script mínimo que implementa esos cuatro pasos, sin tocar las notas que ya tienen frontmatter:

python 
inbox = VAULT / "Inbox"
destino = VAULT / "Zettelkasten"
destino.mkdir(exist_ok=True)

for nota in inbox.rglob("*.md"):
    if (destino / nota.name).exists():
        continue  # evita sobrescribir una nota existente
    texto = nota.read_text(encoding="utf-8")
    if texto.startswith("---"):
        continue  # ya tiene frontmatter
    datos = analizar_nota(texto)
    frontmatter = "---\ntags: [" + ", ".join(datos["tags"]) + "]\n---\n\n"
    resumen = "## Resumen IA\n" + "\n".join(f"- {p}" for p in datos["resumen"]) + "\n\n"
    nota.write_text(frontmatter + resumen + texto, encoding="utf-8")
    nota.rename(destino / nota.name)

Esta automatización se puede orquestar ejecutando el script en segundo plano o utilizando un plugin de Obsidian (como Shell commands) para invocar el binario de Python directamente desde un atajo de teclado en la interfaz.
