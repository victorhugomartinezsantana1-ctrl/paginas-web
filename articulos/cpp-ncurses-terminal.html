C++ en la Terminal: Interfaces con Ncurses

Crea herramientas TUI, juegos y calculadoras vectoriales gestionando el buffer de la consola.

por Victor Martinez 2026-10-23 ⏱ 20 min de lectura

1. Más allá de std::cout

std::cout procesa streams de texto de forma lineal. Para crear aplicaciones interactivas en la terminal (como htop, juegos de Snake, o editores como vim), necesitas posicionar el cursor en coordenadas arbitrarias (X, Y) y capturar eventos de teclado sin esperar a que el usuario presione Enter. Aquí entra ncurses.

2. Inicialización y Gestión de Memoria (El Bucle de TUI)

Ncurses trabaja con "ventanas" (buffers de memoria). Debes inicializar la pantalla, modificar el buffer interno y luego volcarlo a la terminal física mediante un refresco.

cpp 
#include <ncurses.h>

int main() {
    initscr();             // Inicializa el modo ncurses
    cbreak();              // Deshabilita el buffer de línea (lectura inmediata)
    noecho();              // Las teclas presionadas no se imprimen en pantalla
    keypad(stdscr, TRUE);  // Captura teclas especiales (flechas direccionales)

    // Escribir en coordenadas (Y, X) - Ncurses invierte el orden estándar
    mvprintw(10, 20, "Calculadora Vectorial 3D - Presiona 'q' para salir");
    refresh();             // Vuelca el buffer a la pantalla real

    int ch;
    while((ch = getch()) != 'q') {
        // Lógica interactiva aquí
        if (ch == KEY_UP) {
            mvprintw(11, 20, "Flecha ARRIBA detectada!   ");
        }
        refresh();
    }

    endwin(); // Restaura la terminal a su estado original (Crítico)
    return 0;
}

Para compilar hay que enlazar la biblioteca (en Debian/Ubuntu se instala con sudo apt install libncurses-dev):

bash 
g++ main.cpp -o tui -lncurses

3. Programación Orientada a Objetos en TUI

Al construir una calculadora vectorial, abstrae la lógica del dibujo. Crea clases en C++ que encapsulen el estado (class Vector3D, class Fuerza) y pasa un puntero de la ventana de ncurses (WINDOW*) a una clase de renderizado (UIDisplay) para mantener el backend matemático completamente separado del frontend gráfico en consola.
