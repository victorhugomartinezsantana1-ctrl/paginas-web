Investigación Profunda: Python pathlib vs os.path

Manipulación de sistemas de archivos orientada a objetos: globbing, permisos, lectura binaria y jerarquías.

por Victor Martinez 2026-10-08 ⏱ 14 min de lectura

1. El Paradigma Orientado a Objetos de Pathlib

Históricamente, Python usó os.path, tratando las rutas como meras cadenas de texto (Strings). Esto obligaba a anidar llamadas como os.path.join(os.path.dirname(os.path.abspath(__file__)), 'data'). El módulo pathlib, introducido en Python 3.4, representa las rutas como objetos, sobrecargando el operador / para concatenar directorios elegantemente.

2. Path vs PurePath

  • PurePath (y PurePosixPath / PureWindowsPath): Manipula la ruta sin interactuar con el sistema de archivos real. Útil para trabajar con rutas de Windows desde un entorno Linux, por ejemplo.
  • Path (y PosixPath / WindowsPath): Hereda de PurePath pero añade llamadas al sistema (I/O) como crear, leer, escribir y verificar existencia (.exists()).

3. Atributos Esenciales de un Objeto Path

Dado archivo = Path('/var/log/nginx/access.log'):

  • archivo.name -> 'access.log' (Nombre con extensión)
  • archivo.stem -> 'access' (Nombre sin extensión)
  • archivo.suffix -> '.log' (Última extensión)
  • archivo.suffixes -> Útil para archivos como .tar.gz (Devuelve ['.tar', '.gz'])
  • archivo.parent -> Path('/var/log/nginx')
  • archivo.parents[0] -> (Igual que parent), [1] -> /var/log, etc.

4. Operaciones I/O Aceleradas

Pathlib permite omitir el clásico patrón with open(...) en lecturas y escrituras sencillas. Ojo: write_text() no es atómico; si el proceso se interrumpe a mitad de la escritura, el archivo puede quedar incompleto.

python 
from pathlib import Path

ruta = Path('datos.json')

# Escritura de texto (sobrescribe si existe)
ruta.write_text('{"status": "ok"}', encoding='utf-8')

# Lectura directa
contenido = ruta.read_text(encoding='utf-8')

# Manipulación Binaria
imagen = Path('foto.png')
datos_binarios = imagen.read_bytes()

5. Caso de Uso Completo: Limpieza de Logs Antiguos

Este script busca recursivamente todos los archivos .log, verifica la fecha de modificación (usando stat().st_mtime) y elimina aquellos más antiguos de 30 días, manejando permisos.

python 
import time
from pathlib import Path

directorio_logs = Path('/var/log/mi_app')
tiempo_limite = time.time() - (30 * 24 * 60 * 60) # Hace 30 días en segundos

# rglob hace búsqueda recursiva
for log_file in directorio_logs.rglob('*.log'):
    if log_file.is_file():
        try:
            # Obtener metadata del archivo
            fecha_modificacion = log_file.stat().st_mtime
            if fecha_modificacion < tiempo_limite:
                log_file.unlink() # Equivalente a os.remove()
                print(f"Eliminado: {log_file.name}")
        except PermissionError:
            print(f"Acceso denegado para borrar: {log_file}")
