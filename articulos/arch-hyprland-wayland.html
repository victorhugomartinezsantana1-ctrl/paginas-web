Arch Linux + Wayland: Dominando el Tiling con Hyprland

Despliega y personaliza un compositor Wayland dinámico para crear un entorno minimalista y fluido.

por Victor Martinez 2026-10-25 ⏱ 15 min de lectura

1. El Fin de X11 y el Ascenso de Wayland

El protocolo X11 arrastra código de los años 80, gestionando eventos a través de un servidor centralizado propenso al "tearing" (desgarro de pantalla) e inseguro por naturaleza (cualquier app puede leer las teclas de otra). Wayland resuelve esto delegando el renderizado directamente a los clientes y al Compositor, asegurando frames perfectos y aislamiento de seguridad.

2. ¿Por qué Hyprland?

Hyprland es un compositor dinámico de mosaicos (tiling) escrito en C++. A diferencia de i3 o Sway, renderiza las ventanas en la GPU con su propio backend, Aquamarine (desde 2024; antes usaba wlroots), permitiendo animaciones fluidas, bordes redondeados y desenfoque (blur) sin consumir apenas CPU.

En Arch se instala desde los repositorios oficiales, junto con las herramientas básicas que usaremos más abajo:

bash 
sudo pacman -S hyprland waybar wofi alacritty

Desde una TTY, inicia la sesión con el comando Hyprland (o elige "Hyprland" en tu gestor de inicio de sesión). El paquete incluye una configuración de ejemplo en /usr/share/hypr/hyprland.conf que puedes copiar como punto de partida.

3. Anatomía del hyprland.conf

Todo el comportamiento se define en ~/.config/hypr/hyprland.conf. Aquí defines monitores, variables de entorno e IPC (Inter-Process Communication).

hyprland.conf 
# Monitor principal a 144Hz
monitor=DP-1, 1920x1080@144, 0x0, 1

# Variables para forzar Wayland en apps problemáticas
env = XDG_SESSION_TYPE,wayland
env = QT_QPA_PLATFORM,wayland

# Tiling (Dwindle)
dwindle {
    pseudotile = true
    preserve_split = true
}

# Atajos de teclado (Binds)
$mainMod = SUPER
bind = $mainMod, Return, exec, alacritty # Lanzar terminal
bind = $mainMod, Q, killactive,          # Cerrar ventana
bind = $mainMod, Space, exec, wofi --show drun # Lanzador

4. Ecosistema de Herramientas

Hyprland no incluye barra de tareas ni notificaciones. Debes ensamblar tu sistema modularmente:

  • Barra de estado: Waybar (configurable con JSON/CSS).
  • Notificaciones: Dunst o Mako.
  • Fondos de pantalla: hyprpaper o swaybg.
  • Terminal: Alacritty o Kitty (ambos nativos de Wayland y acelerados por GPU).
