Gestión Avanzada de Particiones en Dual-Boot

Eliminación de Linux, extensión de la partición de Windows y restauración del arranque con bcdboot.

por Victor Martinez 2026-10-24 ⏱ 12 min de lectura

1. Estructura de Disco: UEFI y GPT

En sistemas modernos, la tabla de particiones MBR es obsoleta; usamos GPT junto con UEFI. En un esquema dual-boot, existe una partición crítica llamada EFI System Partition (ESP), formateada en FAT32 (usualmente 100-500MB). Aquí conviven pacíficamente el gestor de arranque de Windows (bootmgfw.efi) y GRUB/Systemd-boot.

2. Eliminación de Linux para Extender Windows

Cuando eliminas una distribución Linux (ej. Linux Mint) para darle espacio a Windows, NO debes simplemente borrar todo el disco, ya que Windows dejará de arrancar si destruyes GRUB de forma abrupta.

Antes de empezar: haz una copia de seguridad de tus datos. Una partición eliminada por error es muy difícil de recuperar.

Flujo Correcto (Desde Windows):

  1. Restaurar Bootloader: Ejecuta la terminal como Administrador y usa bcdboot C:\Windows para asegurar que el Windows Boot Manager asuma el control. Opcionalmente puedes montar la partición EFI con diskpart y borrar la carpeta \EFI\ubuntu (o la que haya creado tu distribución).
  2. Borrar Partición Ext4/Btrfs: Usa la herramienta "Administración de discos" (o un software como AOMEI Partition Assistant) para eliminar el volumen donde residía Linux. Ese espacio quedará como "Espacio no asignado" (Unallocated space).
  3. Extender Volumen (C:): Haz clic derecho en tu partición C: y selecciona "Extender volumen". El sistema fusionará el espacio no asignado a tu partición NTFS en vivo, sin perder datos.
Requisito de "Extender volumen": el espacio no asignado debe quedar justo a la derecha de C:. Si hay otra partición en medio (por ejemplo la de recuperación de Windows), la opción aparecerá en gris y tendrás que mover esa partición con una herramienta de terceros.

3. Sistemas de Archivos: NTFS vs Ext4

Compatibilidad: Linux puede leer y escribir perfectamente particiones de Windows (NTFS) usando el driver integrado ntfs-3g (o el nuevo driver de kernel ntfs3). Sin embargo, Windows es inherentemente "ciego" a particiones de Linux (Ext4, Btrfs, XFS) a menos que uses software de terceros o WSL2.
